Grand War 1914 — Android Offline v0.1

این نسخه شامل Prototype آفلاین بازی، AI، منابع، واحدها، ژنرال‌ها،
سناریوها و Sandbox/Mod است.

ساخت APK:
1. کل محتویات این پروژه را در یک GitHub repository قرار دهید.
2. به Actions بروید.
3. workflow با نام Build Grand War 1914 APK را انتخاب کنید.
4. Run workflow را بزنید.
5. پس از اتمام، Artifact با نام GrandWar1914-Offline-v0.1 را دانلود کنید.
6. APK داخل آن را روی Android نصب کنید.

نکته: نسخه 0.1 پایه قابل توسعه است. ویژگی‌های بزرگ‌تر مانند نقشه جهان،
کمپین‌های کامل WWI/WWII، تکنولوژی عمیق، دیپلماسی، جاسوسی، AI پیشرفته‌تر
و محتوای بیشتر برای نسخه‌های بعدی در نظر گرفته شده‌اند.
